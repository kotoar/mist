迷雾科 · 排版体例

FOUNDATIONS

迷雾档案与 DeepClue 侦探事务所同出一馆:同一套语法——语义变量、三族字体、以线分栏、[方括号] 行动——只换情绪。事务所是黄铜与旧纸,迷雾档案是夜雾与冷墨。本次为换皮改版:页面信息与文案一律沿用现有站内文本,不增删、不改写;本册只规定皮怎么画。凡此处未立之规,从 DeepClue 体例。

03

分隔线

RULES

不用阴影、不用圆角卡片作分隔。版面靠线说话:细线分行分栏,点线分明细,双线收一节之口;线索卡以左侧竖线记状态——灰为未解,雾青为已解。

04

行动语言

ACTIONS

凡雾青,必可点;凡可点,必雾青。双重信号:凡可点之处,既是雾青,又套 [直角括号]——导航、行动、筛选概莫例外,悬停再浮一层极浅雾底;当前页导航项雾底常驻。按钮文字沿用站内原文(提交、结束游戏、我想看答案、跳过当前问题、侦探手册、所有档案……),只换包装,不换词;危险操作(结束游戏)用朱红。

06

雾的规矩

FOG RULES

全站过渡一律 0.15 秒纯色,不缩放、不弹跳。唯一的例外是「揭示」:验证命中的那一刻,线索从雾里显形——0.5 秒,模糊由 7px 散尽,透明度由零升满(命中的线索按站内现有逻辑标红)。这是迷雾档案唯一的动效特权,只给这一个时刻,不得挪用。

07

文案体例

COPY
换皮不换词

本次改版只重制 UI 风格,不改动信息与文案:页面结构、栏目名(主页 / 档案 / 迷雾 / 解谜 / 实验室)、按钮动词(提交 / 结束游戏 / 我想看答案 / 跳过当前问题 / 侦探手册)、提示语(不完全正确。进度:N% / 回答错误 (N / 100) / 恭喜完成故事!)、开发部与侦探手册全文,一律沿用站内现有文本。将来若要为迷雾档案另立叙事化文案,单独提案,不随换皮夹带。
